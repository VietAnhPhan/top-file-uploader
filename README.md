# 🌱 Environment Variables for Top File Uploader

Create a `.env` file in the **root directory** of your project and copy the following variables into it.  
Update the values as needed for your local development or production environment.

---

## Example `.env` File

```dotenv
# Server configuration
PORT=your_port_here    # The port your app will run on

# Database configuration
DATABASE_URL='postgresql://username:password@localhost:5432/databasename?schema=public'
DB_PORT=5432

# API Keys (if using third-party APIs)
SUPABASE_URL=your_url_here
SUPABASE_API=your_api_key_here
